# EasyPark — YOLO26n USB Camera

**EasyPark** — интеллектуальная система мониторинга парковочных мест с использованием компьютерного зрения и нейронной сети **YOLO26n Object Detection**.

Данный модуль отвечает за обнаружение автомобилей на парковочном макете с помощью USB-камеры, определение занятости парковочных мест и визуализацию результатов в реальном времени.

Модуль является частью проекта [EasyPark](https://github.com/penxick/EasyPark).

---

## 1. Возможности

- Обнаружение игрушечных автомобилей с помощью обученной YOLO26n.
- Определение занятости восьми парковочных мест.
- Отображение ограничивающих прямоугольников (*bounding boxes*) вокруг обнаруженных автомобилей.
- Визуализация свободных и занятых парковочных мест.
- Автоматическое выравнивание изображения с помощью четырёх ArUco-маркеров.
- Подключение USB-камеры с возможностью выбора индекса устройства.
- Работа нейросети на видеокартах NVIDIA с поддержкой CUDA.
- Сбор фотографий, ручная разметка и повторное обучение модели.

## 3. Принцип работы

Система выполняет следующие действия:

1. Получает видеопоток с USB-камеры.
2. Находит четыре ArUco-маркера, расположенные по углам парковочного макета.
3. Вычисляет перспективное преобразование изображения.
4. Выравнивает изображение парковки.
5. Передаёт изображение обученной нейросети YOLO26n.
6. Получает координаты обнаруженных автомобилей.
7. Сопоставляет автомобили с парковочными местами P1–P8.
8. Определяет количество свободных и занятых мест.
9. Отображает результат в реальном времени.

### Цветовая индикация

- **Зелёный прямоугольник** — свободное парковочное место.
- **Красный прямоугольник** — занятое парковочное место.
- **Голубой прямоугольник** — обнаруженный нейросетью автомобиль.

В отличие от классификации целого парковочного места, Object Detection позволяет обнаруживать отдельные автомобили и определять их координаты.

## 5. Установка

### Требования

- Windows 10/11.
- Python 3.11.
- USB-камера.
- Четыре распознаваемых ArUco-маркера.
- Установленные библиотеки Python.
- Видеокарта NVIDIA рекомендуется для ускорения нейросети.

### 5.1. Создание виртуального окружения

Откройте терминал PowerShell в папке `Yolo26nUSBcamera`.

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

После активации появится префикс `(.venv)`.

### 5.2. Установка PyTorch с CUDA

Для совместимой видеокарты NVIDIA можно установить протестированную конфигурацию PyTorch с CUDA 12.1:

```powershell
python -m pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
```

Проверьте доступность CUDA:

```powershell
python -c "import torch; print(torch.cuda.is_available())"
```

Ожидаемый результат:

```text
True
```

При отсутствии NVIDIA CUDA можно использовать процессор, изменив `device=0` на `device="cpu"` в соответствующем скрипте.

### 5.3. Установка остальных библиотек

```powershell
python -m pip install ultralytics==8.4.178 opencv-contrib-python numpy
```

Для работы ArUco требуется версия OpenCV с модулем `cv2.aruco`.

## 6. Определение индекса USB-камеры

**Важно:** Windows может присваивать разным камерам разные индексы. Если подключена виртуальная камера, OpenCV может выбрать её вместо физической USB-камеры.

Для проверки запустите:

```powershell
python find_camera.py
```

Программа последовательно проверяет доступные камеры.

Управление:

- `N` — перейти к следующей камере.
- `Q` — завершить поиск.

Найдите камеру, показывающую парковочный макет.

Затем откройте `parking_detection_live.py` и измените параметр:

```python
CAMERA_INDEX = 2
```

Вместо `2` укажите найденный индекс.

Для подключения используется OpenCV с backend `cv2.CAP_MSMF`.

## 7. Настройка модели YOLO26n

Файл обученной модели находится в корне папки:

```text
Yolo26nUSBcamera/easypark_yolo26n_best.pt
```

В `parking_detection_live.py` должен использоваться следующий путь:

```python
MODEL_PATH = BASE_DIR / "easypark_yolo26n_best.pt"
```

Это позволяет запускать модуль без дополнительной папки с результатами обучения.

Модель обучена обнаруживать один класс:

```text
0 — car
```

Для каждого обнаруженного автомобиля нейросеть возвращает координаты ограничивающего прямоугольника и оценку уверенности обнаружения.

## 8. Настройка ArUco-маркеров

Для определения положения макета используются четыре маркера из словаря:

```python
cv2.aruco.DICT_4X4_50
```

Расположение маркеров:

| ID | Положение |
|---|---|
| 0 | Верхний левый угол |
| 1 | Верхний правый угол |
| 2 | Нижний левый угол |
| 3 | Нижний правый угол |

Для корректного выравнивания изображения желательно, чтобы камера одновременно распознавала все четыре маркера.

При успешном обнаружении отображается:

```text
MARKERS: 4/4
```

Если маркеры не обнаружены, проверьте освещение, угол обзора и отсутствие перекрытий.

## 9. Запуск EasyPark YOLO26n

После настройки камеры и модели выполните:

```powershell
python parking_detection_live.py
```

Программа откроет два окна.

**EasyPark — Camera**

- Исходное изображение USB-камеры.
- Обнаруженные ArUco-маркеры.
- Количество распознанных маркеров.

**EasyPark — Car Detection**

- Выровненное изображение парковки.
- Bounding boxes обнаруженных автомобилей.
- Границы парковочных мест P1–P8.
- Количество свободных и занятых мест.

Для завершения программы нажмите `Q` в окне OpenCV.

## 10. Обучение нейросети

Для обучения YOLO26n был собран собственный датасет изображений парковочного макета.

В процессе использовались:

- 105 фотографий макета в разных конфигурациях.
- Ручная разметка автомобилей с помощью bounding boxes.
- Примеры парковки с автомобилями и посторонними предметами.
- YOLO Object Detection с одним классом `car`.

Подготовка данных выполнялась скриптом:

```powershell
python prepare_detection.py
```

Обучение запускалось командой:

```powershell
python train_detection.py
```

Основные параметры обучения:

| Параметр | Значение |
|---|---|
| Архитектура | YOLO26n |
| Задача | Object Detection |
| Класс | car |
| Максимум эпох | 100 |
| Размер входного изображения | 640 |
| Batch size | 8 |
| GPU | NVIDIA GeForce RTX 3060 Ti |
| Early stopping patience | 25 |

**Примечание:** исходный датасет не включён в эту папку GitHub. Для повторного обучения понадобятся фотографии, разметка и подготовленный `data.yaml`. Скрипты подготовки предполагают наличие соответствующих локальных директорий.

## 11. Ограничения

Текущая модель обучена для демонстрационного бумажного макета EasyPark с восемью парковочными местами и используемыми игрушечными автомобилями.

Следует учитывать:

- Результаты зависят от освещения и качества изображения камеры.
- При значительном изменении условий съёмки возможны ошибки обнаружения.
- Текущий `parking_spaces.json` содержит координаты конкретного макета.
- Для другого расположения парковочных мест потребуется новая схема.
- Модель может ошибочно обнаруживать некоторые посторонние предметы как автомобили.
- Использование на реальных городских парковках потребует дополнительного обучения и тестирования на соответствующих данных.
