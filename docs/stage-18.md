# Этап 18 — CV Test

Добавлен пользовательский CLI для отправки локального JPEG/PNG в POST /detect
и получения JSON с найденным транспортом. Этап 19 не начат; Flutter не интегрирован.

## Использование

Из D:\EasyPark при запущенном CV-сервисе:

```powershell
python cv-service/tools/detect_image.py "D:\Pictures\parking.jpg"
```

Используется стандартная библиотека Python. Модель работает в прежнем контейнере;
устанавливать ML-зависимости на Windows не требуется. URL по умолчанию —
http://127.0.0.1:8000/detect, переопределяется параметром --url. CLI ограничивает
чтение файла 5 МиБ, распознаёт JPEG/PNG по сигнатуре, отправляет бинарное тело
с правильным Content-Type и ожидает ответ до 60 секунд. Полную валидацию изображения
выполняет сервер. Изображения в сервисе по-прежнему не сохраняются.

Успех: JSON в stdout и код 0, включая пустой vehicles. Ошибка: сообщение в stderr
и код 1; HTTP-ошибки содержат статус. Повторов запроса автоматически нет.
