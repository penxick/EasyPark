# Этап 19 — Подготовка собственной модели

Добавлена возможность положить веса в `cv-service/models/best.pt` и выбрать
их через MODEL_PATH. Обучение не выполнялось; этап 20 не начат.

## Подключение

Положите доверенные совместимые веса Ultralytics YOLO detection в указанный файл.
В корневом `.env` задайте `MODEL_PATH=/app/models/best.pt`, затем выполните
`docker compose up -d --force-recreate cv-service`.
Каталог models подключается только для чтения. Файл best.pt не поставляется.
Текущий рабочий контейнер оставлен на стандартной YOLO11n.

По умолчанию используется weights/yolo11n.pt. При прямом запуске относительный
путь отсчитывается от cv-service, абсолютный путь тоже допустим. В Compose путь
задаётся внутри Linux-контейнера. URL, отсутствующий файл и расширение не .pt
отвергаются до загрузки. Повреждённые веса и модель другого назначения не дают
readiness: API возвращает 503 без скрытой подмены на стандартную модель.
После успешного прогрева классы сопоставляются с библиотекой этапа 17.
