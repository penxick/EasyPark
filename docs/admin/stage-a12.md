# A12 — Analytics Flutter

Дата: 2026-10-11. Реализован этап A12. A13 не начат.

## Реализация

Защищённый маршрут /admin/analytics заменяет заглушку. Используются готовые
GET admin/analytics и admin/analytics/parkings, общий ApiClient и Role redirect.
Показаны парковки, места, пользователи, все и активные бронирования, четыре
статуса мест и общий процент загрузки доступных мест.

Круговая диаграмма отображает распределение FREE/OCCUPIED/RESERVED/UNAVAILABLE.
Под диаграммой есть текстовые значения, не требующие распознавания цветов.
По каждой парковке показаны название, все счётчики мест, загрузка, все и активные
бронирования. Полосы сравнения бронирований масштабируются по максимуму текущей
страницы; это явно подписано. Загрузка имеет постоянную шкалу 0–100%.

Значения и проценты поступают из backend A6. Физическая занятость не прибавляется
повторно к распределению статусов. При нулевых данных нет деления на ноль.
Список имеет серверную пагинацию по 20 элементов. Общая аналитика и список имеют
независимые состояния загрузки/ошибки, retry, обновление кнопкой и жестом, а также
при возвращении приложения. Устаревшие ответы отбрасываются LoadController.

Из локального RevenueAnalytics.tsx взяты композиция карточек и диаграмм,
использован существующий Flutter UI-kit. Выручка, почасовые демоданные и топ
автомобилей не перенесены: они не предусмотрены текущим API/ТЗ. Новых зависимостей,
таблиц и backend endpoints нет. React-код не переносился.
