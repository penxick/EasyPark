# A11 — пользователи и бронирования Flutter

Дата проверки: 2026-10-11. Реализован только этап A11; A12 не начат.

## Возможности

Заглушки пользователей и бронирований заменены рабочими экранами. Используются
готовые ADMIN endpoints A5, общий ApiClient и существующая защита маршрутов.
Список пользователей показывает ID, имя, email, роль и дату регистрации.
Карточка пользователя содержит количество всех и активных бронирований,
историю с пагинацией и переход к конкретному бронированию.

Бронирования имеют категории «Все», «Активные», «Завершённые», «Отменённые».
Списки и история загружаются страницами по 20 записей. Карточка бронирования
показывает ID, пользователя и email, парковку и адрес, код места, дату создания,
начало, окончание и статус. Есть переход к карточке пользователя.

Реализованы loading, empty, error, retry, обновление жестом и кнопкой.
LoadController предотвращает замену выбранной категории устаревшим ответом.
Используются существующие карточки, ProfileDetails и модели; passwordHash
не входит в модели интерфейса. Ответы API проверяются перед отображением.
