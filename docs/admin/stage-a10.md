# A10 — Управление ParkingSpace во Flutter

Дата: 11 октября 2026 года.

## Реализация

Маршрут /admin/parkings/:id/spaces теперь открывает рабочий экран вместо заглушки.
Вход — «Управлять местами» в списке/карточке парковки. Для каждого места показаны
код, статус, physicalOccupied, hasActiveReservation, X/Y и наличие контура.
Цвета и карточки используют прежний UI-kit и локальный Figma ParkingMonitor.

Создание использует POST A4, принимает code, x, y, polygon; начальный FREE
устанавливает backend. Форма проверяет непустой код до 20 символов, локальную
уникальность, конечные X/Y >= 0 и контур из 3–1000 пар конечных чисел.
Контур вводится вершинами X; Y, по одной на строку; пустое поле означает null.
Десятичная запятая поддерживается. Backend остаётся окончательным валидатором.

Редактирование отправляет только изменённые поля. Неизменённый контур не
отправляется в PATCH; physicalOccupied и статус никогда не передаются из формы.
Административная модель содержит существующий ParkingSpace, добавляя контур и
флаг брони, без изменения поведения пользовательской модели.

Отключить/вернуть в эксплуатацию отправляет только available. Backend A4
сам определяет FREE/OCCUPIED/RESERVED при включении. Отключение не отменяет
существующую бронь. Физическая занятость не смешивается с наличием брони.
Данные перечитываются после mutations, по кнопке/жесту обновления и при возврате
приложения на передний план, если форма не открыта. CV-service не изменялся.

Удаление выделено красной кнопкой, требует подтверждения. Конфликт с историей
бронирований показывает понятную ошибку. ApiClient сохраняет только разрешённые
машинные коды SPACE_CODE_EXISTS/SPACE_HAS_RESERVATIONS/SPACE_HAS_RELATED_DATA/
SPACE_BUSY; произвольные сообщения и stack trace не отображаются. Старые общие
сообщения ApiException сохранены. Все операции используют прежний JWT и ADMIN API.

Предусмотрены loading, success, empty, error/retry, сохранение ввода при ошибке,
блокировка повторного сохранения и действий во время запроса. При ошибке
mutation экран прокручивается к сообщению. Макет адаптивен, включая крупный текст.
